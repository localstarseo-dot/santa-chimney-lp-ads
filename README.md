# Santa Chimney LP Ads

Local source for four ad landing page variants, with shared header, voucher popup, footer, and floating call/booking actions. LP 1 follows the supplied repair-only paid-search wireframe: rotating repair hero, six problem cards, three interactive before/after projects, repair experience, three relevant reviews, process, compact service directories and FAQs. The duplicated final CTA is removed; the approved compact review-platform and credential layout now lives in the shared footer. LP 2–4 have not been built. WordPress migration comes later.

## Edit and preview

Edit `src/`, then run `npm run build` or `node scripts/build.mjs`. Start the preview with `npm run preview` or `node scripts/preview.mjs`.

Run `npm run validate` before committing or publishing.

## Source and generated files

- `src/components/header.html` and `voucher-modal.html`: shared Gutenberg Group/Custom HTML/Shortcode markup. The popup is a sibling of the header.
- `src/components/footer.html` and `floating-actions.html`: shared footer and floating actions.
- `src/styles/shared.css`: shared header/popup and all supplied LP 1 section styles. Footer and floating-action styles join it during the build into one shared stylesheet, `assets/css/shared.css`.
- `src/scripts/header.js` and `voucher-modal.js`: shared behavior, including native Forminator success handlers.
- `src/pages/lp-1.html`: one editable HTML body containing all LP 1 sections. There are no separate section includes or Gutenberg conversion requirements for local development.
- `src/scripts/service-stats.js`, `comparison.js`, and `google-reviews.js`: progressive counting, before/after interaction, and progressive review enhancement. LP 1's dark reviews run a right-to-left loop on desktop and mobile, using one inert, accessibility-hidden copy of the original group. Pause/Resume, hover/focus/press pause, offscreen and hidden-tab suspension, and a reduced-motion/manual-scroll fallback remain available.
- `src/scripts/hero-slideshow.js`: the five supplied repair photos crossfade behind the stationary hero content every three seconds, using a 1000ms opacity transition with no horizontal movement. The first is discoverable in HTML; subsequent images are fetched one ahead. JC requested removal of the visible Pause/Play button. Reduced-motion users get a static background. Playback pauses when the hero is offscreen, the tab is hidden, or the voucher popup is open. Failed or unloaded images never replace a loaded active image. This decorative autoplay without a user pause control is not claimed to meet WCAG's pause/stop requirements.
- LP 1 hero layout: desktop uses one aligned content column up to 640px, with equally sized CTAs. Google/Yelp logos and the Google rating share the first trust row; credentials and the payment group share the second. “We Accept All Cards” stays centered directly above its four logos. Tablet through 1023px uses a centered content area; 640px and below stacks CTAs and centers all four trust/payment groups. No empty photo grid column remains. Shared CSS owns these responsive rules; copy, assets and behavior are unchanged.
- `src/styles/preview.css` and `src/scripts/preview-forms.js`: staging only.
- `sources/`: unchanged supplied Gutenberg, CSS, and JS reference files. The separately supplied popup CSS/JS matched the embedded originals.
- `index.html`, `lp-1/index.html`, `assets/css/`, `assets/js/`, `wordpress/`: generated by the build. Edit source, then rebuild.

Generated static output is committed alongside source for GitHub Pages. The Pages source is `main` at `/`; `.nojekyll` is included.

## Preview form behavior

GitHub Pages cannot render Forminator shortcodes. During the static build only, forms 4877 and 4914 are replaced by name/phone preview forms using the supplied selectors. These forms send no requests, save no contact details, and label simulated success as a preview. A form shape is inferred from the supplied field selectors, not an export of the live plugin configuration.

LP 1 uses a staging-specific expiry key, independent of production and future variants. The shared timer is 3540 seconds, persists across reloads, and restarts when an unclaimed timer reaches zero. The popup can open once per page load, five seconds after scrolling beyond 80px or using an in-page body link. Reloading at an already-scrolled position also counts as engagement. It will not interrupt input fields, a hidden tab, or a claimed voucher. A deferred invitation can retry after leaving a field or returning to the tab. Closing it suppresses automatic reopening for the current page load, not future reloads. Old session-storage seen/dismissed flags are no longer used. The local preview-control row remains removed. Staging forms still simulate success; the approved popup remains available through its engagement trigger.

The repair-focused hero intentionally supersedes the previously approved broad-service hero, following JC's new wireframe. Copy, statistics, reviews, credentials, contact details, offer wording, and booking URL use supplied values. Business statistics (including the new supplied 874+ repair wording), review excerpts, credentials, and offer terms still require owner confirmation before an ad launch. No analytics or CRM integration has been added. Phone tracking belongs in the production head; no inline onclick tracking is added.

LP 1 prioritizes Betty (Inspection & Repair), N. Kuyer (Fireplace & Liner Repair), and A. Gleizer (Chimney Leak Repair). Their supplied excerpts remain unchanged. Charcoal cards move continuously right to left on desktop and mobile, with equal original/duplicate group widths for a seamless loop. Reduced-motion users and browsers without enhancement support get manual scrolling without a duplicate. No live GBP feed is connected.
