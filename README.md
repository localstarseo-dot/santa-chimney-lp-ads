# Santa Chimney LP Ads

Local source for four ad landing page variants, with shared header, voucher popup, footer, and floating call/booking actions. LP 1 currently contains the supplied global components; its page body is pending. LP 2–4 have not been built. The current focus is the assembled local preview; WordPress migration comes later.

## Edit and preview

Edit `src/`, then run `npm run build` or `node scripts/build.mjs`. Start the preview with `npm run preview` or `node scripts/preview.mjs`.

Run `npm run validate` before committing or publishing.

- Dashboard: http://127.0.0.1:4173/santa-chimney-lp-ads/
- LP 1: http://127.0.0.1:4173/santa-chimney-lp-ads/lp-1/

The preview includes the repository path used by GitHub Pages. All packaged asset links are relative. No dependencies are required beyond Node.js.

## Source and generated files

- `src/components/header.html` and `voucher-modal.html`: shared Gutenberg Group/Custom HTML/Shortcode markup. The popup is a sibling of the header.
- `src/components/footer.html` and `floating-actions.html`: shared footer and floating actions.
- `src/styles/shared.css`, `footer.css`, and `floating-actions.css`: component styles compiled into one shared stylesheet.
- `src/scripts/header.js` and `voucher-modal.js`: shared behavior, including native Forminator success handlers.
- `src/pages/lp-1.html`: preview placeholders for the supplied navigation anchors, pending the real LP 1 sections.
- `src/styles/preview.css` and `src/scripts/preview-forms.js`: staging only.
- `sources/`: unchanged supplied Gutenberg, CSS, and JS reference files. The separately supplied popup CSS/JS matched the embedded originals.
- `index.html`, `lp-1/index.html`, `assets/css/`, `assets/js/`, `wordpress/`: generated by the build. Edit source, then rebuild.

Generated static output is committed alongside source for GitHub Pages. The Pages source is `main` at `/`; `.nojekyll` is included.

## Preview form behavior

GitHub Pages cannot render Forminator shortcodes. During the static build only, forms 4877 and 4914 are replaced by name/phone preview forms using the supplied selectors. These forms send no requests, save no contact details, and label simulated success as a preview. A form shape is inferred from the supplied field selectors, not an export of the live plugin configuration.

LP 1 uses a staging-specific expiry key, independent of production and future variants. The shared timer is 3540 seconds, persists across reloads, and restarts when an unclaimed timer reaches zero. The popup opens five seconds after load while unclaimed. Closing it does not suppress it on the next reload. Reset preview clears only this page's staging expiry/claim/dismissal keys.

The logos, address, email, phone number, offer wording, and booking URL are supplied values. Logos still load from their supplied WordPress image URLs. No analytics or CRM integration has been added. Phone tracking belongs in the production head; no inline onclick tracking is added.

## Gutenberg migration

`wordpress/header-and-popup.gutenberg.html` is generated from the same component source and retains the real `[forminator_form id="4877"]` and `[forminator_form id="4914"]` Shortcode blocks. Paste it into Gutenberg's code editor when migrating; do not paste the static preview page.

Load `assets/css/shared.css`, `assets/js/header.js`, and `assets/js/voucher-modal.js` once. Do not load `preview.css` or `preview-forms.js` in WordPress. Assign `sc-ppc-header-system` to the header Group; the popup Group uses `sc-voucher-modal` and its inner Group uses `sc-voucher-modal__panel`. CSS remains scoped to these classes.

Keep the popup outside the header in the block tree so the plugin form stays in its rendered container. WordPress must render both Forminator forms and provide its Forminator/jQuery behavior. Preserve `#home.sc-ads-hero`, `#our-work`, and `#request-service` in the finished LP 1 body.

Production form delivery, tracking, responsive theme interactions, and published WordPress behavior require separate verification after migration. No production integration is verified by this static preview.
