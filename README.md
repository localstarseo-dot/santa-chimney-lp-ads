# Santa Chimney LP Ads

Local source for four ad landing page variants, with shared header, voucher popup, footer, and floating call/booking actions. LP 1 follows the supplied repair-only paid-search wireframe: rotating repair hero, six problem cards, three interactive before/after projects, repair experience, three relevant reviews, process, compact service directories and FAQs. LP 2 adapts that layout for cleaning, with three supplied comparison pairs. LP 3 adapts it for inspections, with five hero photos and three photo-only inspection cards. The duplicated final CTA is removed; the approved compact review-platform and credential layout lives in the shared footer. LP 4 has not been built. WordPress migration comes later.

## Edit and preview

Edit `src/`, then run `npm run build` or `node scripts/build.mjs`. Start the preview with `npm run preview` or `node scripts/preview.mjs`.
